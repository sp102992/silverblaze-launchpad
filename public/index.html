This determines whether Ansible Inventory is required, and whether vendor IP whitelisting fields are needed on CIS/Payment Vendor.

Ansible Inventory is not required. Vendor IP whitelisting fields will appear on CIS/Payment Vendor.

    

    

      
      
Client/BU Hosted Server
Ansible Inventory is required, same as today. No change to existing behavior.
